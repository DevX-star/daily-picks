## 🤖 AI 动态 & 免费额度

- **【新发布】Gemini 4 Hydrogen**（Google DeepMind）— 11 月 12 日发布、11 月 16 日更新：Gemini 4 家族里主打速度与效率的一档，专为快速执行多样化 agentic 工作流设计，日常编码和 agent 任务响应更快；已面向所有层级开放，包括 Google AI Studio、Gemini API、Gemini 应用与 Google Search，普通用户现在就能用上。
  [官方公告](https://deepmind.google/blog/introducing-gemini-4-hydrogen/)

- **【幕后工程】Performance Factory**（OpenAI）— 11 月 19 日官方工程博客：OpenAI 公开了他们如何用一套 Codex 驱动的自动化系统持续发现并修复 ChatGPT 的性能问题，把过去靠人工排查的流程变成可配置的自动工作流。想了解大厂怎么做性能工程的，值得一读。
  [官方博客](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)

## ⭐ GitHub 有趣项目

- **[obra/superpowers](https://github.com/obra/superpowers)** · Shell · ★ 323,702（今日 +884）
  一套给编码 agent 用的技能框架加软件开发方法论，把头脑风暴、计划、测试驱动等流程固化成可复用的技能。最近 agent 技能生态大热，这个是源头项目之一，想给自己的 agent 工作流立规矩的人值得研究。

- **[jingyaogong/minimind](https://github.com/jingyaogong/minimind)** · Python · ★ 68,133（今日 +488）
  两小时从零训出一个 64M 参数的小语言模型，完整走一遍预训练到微调的流程。想真正搞懂大模型是怎么训出来的人，这是目前最友好的动手教材之一。

- **[mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)** · Python · ★ 71,971（今日 +566）
  一个 agent 技能：给定任意话题，自动去 Reddit、X、YouTube、Hacker News、Polymarket 和全网搜集最近 30 天的信息，再综合成有依据的摘要。做调研、追热点的人可以直接拿来用。

- **[google-labs-code/stitch-skills](https://github.com/google-labs-code/stitch-skills)** · TypeScript · ★ 11,404（今日 +324）
  Google Labs 出的 Agent Skills 技能库，配合 Stitch MCP 服务器使用，遵循 Agent Skills 开放标准，兼容 Antigravity、Gemini CLI、Claude Code、Cursor 等主流编码 agent。想看官方怎么写技能的，这是范本。

- **[cursor/plugins](https://github.com/cursor/plugins)** · TypeScript · ★ 18,096（今日 +261）
