## 🤖 AI 动态 & 免费额度

- **【研究长文】Perplexity and Intelligence**（OpenAI）— 11 月 22 日由首席科学家 Jakub Pachocki 撰文：OpenAI 首次公开自 GPT-3.5 以来的内部基座模型对数困惑度曲线（已降到 0.8 以下），并主张把困惑度确立为跨模型厂商可比的共同指标，用来支撑行业共享的安全标准。想理解「模型到底怎么变强的」，这篇是难得的一手材料。
  [官方博客](https://openai.com/index/perplexity-and-intelligence/)

- **【落地案例】Hebbia 金融研究实测 GPT-6 Astra**（OpenAI）— 11 月 20 日客户案例：金融研究平台 Hebbia 实测 GPT-6 Astra，在其测试中所需信源类型引用数领先最佳替代方案 13.6 个百分点，引用摘录相关性达 99.5%，演示文稿要求满足率 97.9%。是观察新模型在真实投研流程里表现的一个窗口。
  [官方案例](https://openai.com/business/customer-stories/hebbia/)

- **【观点长文】The Silent Consensus**（OpenAI）— 11 月 18 日刊出的哈佛讲座改编长文：前沿 AI 系统已能发现互联网核心基础设施的重大安全漏洞（文中称之为「Black October」），作者讨论了漏洞发现这类双用途能力带来的治理共识与紧迫性。关心 AI 与网络安全交叉议题的可以读一读。
  [官方博客](https://openai.com/index/the-silent-consensus/)

## ⭐ GitHub 有趣项目

- **[HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything)** · Python · ★ 62,748（今日 +687）
  「让所有软件都变 Agent 原生」：把常用软件包装成 agent 能直接调用的 CLI，并配了一个 CLI-Hub 汇总现成方案。它在 11 月 19 日那期收录过一次，本周再度冲上日榜前列、热度不减，仍在快速迭代，之前错过的人可以补看。

- **[meta/astryx](https://github.com/meta/astryx)** · TypeScript · ★ 32,231（本周热门）
  Meta 开源的设计系统，完全可定制，而且从一开始就为 agent 准备：带 Claude Code 与 Codex 的插件市场，能让编码 agent 直接按这套规范产出界面。做产品又想让 agent 帮你写前端的，值得研究。

- **[we-promise/sure](https://github.com/we-promise/sure)** · Ruby · ★ 17,337（本周热门）
  社区共建的开源个人财务应用，口号是「人人可用、人人共建」，可以自托管记账管钱。不想把财务数据交给商业 App、又想要完整功能的人可以试试。

- **[GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src)** · TypeScript · ★ 10,206（本周热门）
  Google Chrome 团队维护的「现代 Web 最佳实践」技能源：让你的编码 agent 随时跟上最新的 Web 平台规范与写法。用 agent 写前端、又怕它写出过时代码的人，正好拿它当知识补丁。

- **[tradermonty/claude-trading-skills](https://github.com/tradermonty/claude-trading-skills)** · Python · ★ 7,791（本周热门）
  一套给股票投资者和交易者用的 Claude Code 技能：市场分析、技术图表、经济日历、选股筛选与交易策略开发。用 Claude Code 做投研辅助的人可以参考它的技能组织方式；注意这只是工具，不构成任何投资建议。

- **[pookjw/HermesEnabler](https://github.com/pookjw/HermesEnabler)** · Objective-C · ★ 2,403（本周热门）
  在任意 Apple Watch 上启用爱马仕（Hermès）专属表盘的小工具，刚跟进支持 watchOS 27.2 beta。纯属好玩的折腾项目，有 Apple Watch 又爱换表盘的人可以看看，折腾前记得备份。
