## 🤖 AI 动态 & 免费额度

- **【新发布】Shirudo**（OpenAI × Cisco）— 11 月 23 日联合推出的开源运行时：帮运维团队在补丁还没打上之前就护住正在运行的 Linux 系统，不用等补丁、不用重启。在一次受控测试中，一个由 Codex 生成的防护罩在不重启的情况下挡住了针对正在运行的 Elasticsearch 服务的 Java4Shell exploit 尝试。做基础设施和安全的人值得关注。
  [官方公告](https://openai.com/index/introducing-shirudo/)

- **【研究】用 agent 团队 + 形式化验证找更快的量子算法**（Google DeepMind）— 11 月 23 日论文：用多支 Gemini 4 agent 团队改进经典量子算法、生成更高效的量子电路，并用形式化验证把关，目标是聚变能源、化学和酶的模拟。量子硬件还跑不动大问题时，先把算法本身压得更省资源，是一条务实的路。
  [官方博客](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)

- **【新发布】Gemini 4 Neon**（Google DeepMind）— 11 月 18 日发布、11 月 23 日更新确认：主打前沿级智能加快速的端到端任务完成，在复杂软件工程、知识工作和科学工作流上表现突出，定位是能直接进生产环境的编码与工作流模型。已经在用 Gemini 的人可以试试这一档的速度。
  [官方公告](https://deepmind.google/blog/introducing-gemini-4-neon/)

- **【新工具】Genie 4 / Project Genie 新体验**（Google DeepMind）— 11 月 18 日起，Project Genie 推出新体验：首次开放 Genie 4、升级 Genie 3，并加入 Project Genie agent 和社区画廊，生成的互动世界更灵敏、更好共创和分享。门槛：面向符合条件的 Google AI Ultra 订阅用户，不是免费额度，想体验先看清订阅条件。
  [官方公告](https://deepmind.google/blog/genie-4-is-now-available/)

## ⭐ GitHub 有趣项目

- **[cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)** · HTML · ★ 70,936（今日 +624）
  给 Claude Code、Codex、Copilot、Cursor 等编码 agent 用的编辑级图表设计技能：52 种图表类型，输出自包含的 HTML + SVG，主打干净排版、拒绝随手糊的 Mermaid 图。经常让 agent 画架构图、流程图的人值得装。

- **[mjmirza/app-store-compliance](https://github.com/mjmirza/app-store-compliance)** · Shell · ★ 4,927（今日 +755）
  帮你避开 App Store 和 Google Play 常见驳回的开源手册加提交前检查：124 个有记录的驳回模式与修法、隐私清单与 Data safety 检查，还跟踪 112 个合规截止日（EU AI Act、DSA、COPPA 等），并配了给 AI 编码 agent 用的技能。准备上架 App 的独立开发者先过一遍能少踩很多坑。

- **[zhouxiaoka/autoclip](https://github.com/zhouxiaoka/autoclip)** · Python · ★ 14,359（今日 +908）
  开源 AI 视频剪辑桌面工具：一个链接一键出片，把播客、访谈、课程等长视频自动剪成短视频，顺带生成字幕、封面和发布文案，适配抖音、小红书、TikTok、Reels 与 YouTube Shorts。做长视频又要分发短平台的人可以试试。

- **[dream-num/univer](https://github.com/dream-num/univer)** · TypeScript · ★ 31,460（本周热门）
  开源的 Office SDK：把文档编辑、表格计算、协作和文件处理嵌进你自己的产品里，人和 AI agent 都能用。想给产品加一套能在线编辑的文档/表格能力、又不想从零造轮子的人值得看。

- **[kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill)** · Python · ★ 10,227（本周热门）
  给编码 agent 用的本地视频编辑技能：42 个 FFmpeg 工具配机器可读的调用契约和 MCP 服务器，剪辑、字幕、画幅调整、响度、按平台导出都能让 agent 直接干，全程本地、无云端、无需 API key。用 agent 处理视频的人正好补上这一块。
